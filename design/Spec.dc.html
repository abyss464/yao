遥 规格

协议帧

帧 方向 内容 落到哪里
HELLO手机 → 电脑设备 ID，用配对时交换的密钥签名鉴权；未配对即断开
TOUCH手机 → 电脑手机时间戳 + 每帧全部触点（指针 id、x、y），跟随屏幕采样率；电脑按手机原本的节奏重放虚拟触控板
BUTTON手机 → 电脑左 / 右键 按下 · 抬起虚拟触控板
KEY手机 → 电脑Linux evdev 键码 + 按下 · 抬起；长按由电脑自己连发虚拟键盘
MOTION手机 → 电脑陀螺仪换算出的相对位移相对指针
TEXT手机 → 电脑手机输入法已上屏的 UTF-8 文本Wayland 虚拟键盘协议
RUN手机 → 电脑快捷键 IDyaod 展开成按键序列，经虚拟键盘发出
PING双向每 250 ms 一次，顺带测延迟1 秒收不到 → 松开所有按住的键
STATE电脑 → 手机当前窗口 class 与标题、正在播放、Caps / Num 指示灯各页面的实时状态
LIBRARY电脑 → 手机快捷键库，变化时推送快捷键页

交互

  • 触控板：整屏是触控区，底部一条分成左右键；点按、滚动、手势由电脑的 libinput 与 Hyprland 处理；右上「T」调出手机输入法，上屏的字直接送到电脑
  • 遥控器：方向、确定、Esc / Space / F、媒体与音量；正在播放取自电脑的 MPRIS；底部按住挥动手机即移动指针；手机侧键也调电脑音量
  • 键盘：横屏全尺寸；修饰键单击一次、双击锁定、按住即按住；Shift 生效时键帽换成上档字符；Caps 灯跟随电脑；导航区空位切换小键盘；转回竖屏即退出
  • 快捷键：「任意组合键」打开修饰键 + 任意键的组合器；收藏置顶；中间是当前窗口应用的快捷键与序列，「+」录制；最后是 Hyprland 里带描述的绑定，自动读取
  • 电脑名：左上角圆点表示连接状态，点开是设备与设置；延迟变高时才显示毫秒数

服务端：没有界面

  • yaod.service：systemd 用户服务，随 Hyprland 会话启动
  • 监听 20780，mDNS 广播 _yao._tcp，手机自动发现
  • ~/.config/yao/config.toml：端口与监听地址
  • ~/.config/yao/shortcuts.toml：快捷键库唯一存放处，手机上的增改写回这里
  • yao devices / yao revoke：查看、撤销已配对设备
  • 唯一露面的方式是桌面通知：配对码、新设备连上

连接与安全

  • 第一次：手机连上 → 电脑通知弹出 6 位码 → 手机输入后自动连接，双方记下证书指纹与设备密钥
  • 之后：TLS 1.3 + 证书钉扎，未配对的设备连上即断
  • 心跳中断 1 秒，yaod 松开所有按住的键和鼠标键，Ctrl 不会卡死
  • 手机在前台时持有低延迟 Wi-Fi 锁，触点不被省电模式攒批
